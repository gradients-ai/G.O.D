# Training templates

Base training config templates. The diffusion templates are copied into the reference image trainer image and resolved through `trainer/training_paths.py`.

## Contents

| Path | Purpose |
| --- | --- |
| `base.yml` | Axolotl text training template, for reference. |
| `base_grpo.yml` | Axolotl GRPO template, for reference. |
| `base_diffusion_flux.yaml` | Flux ai-toolkit template. |
| `base_diffusion_ideogram4.yaml` | Ideogram 4 ai-toolkit template. |
| `base_diffusion_krea2.yaml` | Krea 2 ai-toolkit template. |
| `base_diffusion_qwen_image.yaml` | Qwen Image ai-toolkit template. |
| `base_diffusion_zimage.yaml` | Z-Image ai-toolkit template. |
