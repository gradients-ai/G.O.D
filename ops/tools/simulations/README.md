# Simulations

Standalone simulation scripts. None of them reads or writes validator state.

## Contents

| Path | Purpose |
| --- | --- |
| `pvp_threshold_sim.py` | Simulates a minimum win-rate threshold in player-versus-player group scoring. |
| `pvp_threshold_sim_v2.py` | The same threshold across many miner compositions with six miners per group. |
| `pvp_threshold_sim_v3.py` | The same threshold when one player dominates one environment. |
| `training_hours_landscape.py` | Sweeps the training-hours formula across model size, row count and tokens per row. |
