# Manual Validator Tools

Manual validator probes and debugging scripts.

## Contents

- `burn_mock_cycle.py`: mock tournament burn/weight cycle probe.
- `check_scoring.py`: scoring inspection script.
- `debug_weight_calculation.py`: weight calculation debugging helper.
- `instruct_eval_container.py`: instruct evaluation container probe.
- `prepare_task_probe.py`: task preparation probe.
- `run_grpo_evaluation.py`: GRPO evaluation runner.
- `run_image_evaluation_probe.py`: image evaluation probe.
- `run_text_evaluation_probe.py`: text evaluation probe.
- `simple_eval_grpo.sh`: shell GRPO evaluation example.
- `task_inspection.sql`: SQL snippets for inspecting task state.
- `tournament_burn_probe.py`: tournament burn calculation probe.
- `__init__.py`: package marker.
